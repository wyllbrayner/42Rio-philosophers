# Informações Gerais
Este projeto integra o quarto ciclo de projetos da [42Rio](https://42.rio/).
Este projeto nos apresenta o problema do [jantar dos filósofos](https://www.deviante.com.br/noticias/entre-forks-e-segredos/) (as instruções gerais deste projeto encontram-se no [en.subject.pdf](./en.subject.pdf) disponibilizado).

Apesar deste desafio possuir uma entrega bônus, que inclui a utilização de semáforos, esta entrega atende, apena, as demandas obrigatórias (utilização de mutex e threads).

A playlist do [CodeVault](https://youtu.be/d9s_d28yJq0?si=9vY2pkPXZd-EcSUf) me ajudou bastante no entendimento do conteúdo exigido neste projeto.

# Como clonar o repositório...
Utilize um sistema operacional baseado no Unix (Linux ou MacOs), clone o [projeto](https://github.com/wyllbrayner/42Rio-philosophers) do **github**.
</br>
</br>

# Como compilar...
### Como compilar o programa philo.
Após clonar o repositório do [projeto](https://github.com/wyllbrayner/42Rio-philosophers), entre na pasta philo e realize o comando **make** no terminal.
Após a mensagem de sucesso aparecer no terminal, um novo arquivo, de nome philo, estará disponível no repositório.
</br>
</br>

# Como utilizar...
### O philo.
Coloque ./philo num_philo tempo_de_vida tempo_comer tempo_dormir [num_refeicoes].

ex: ./philo 4 400 200 200

ou  ./philo 4 400 200 200 5
